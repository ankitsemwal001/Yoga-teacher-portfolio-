## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/ankitsemwal001/Yoga-teacher-portfolio.git
```

### Navigate to Project

```bash
cd Yoga-teacher-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Application will run at:

```
http://localhost:5173
```

---

## 📦 Build for Production

npm run build
